# L&M Som e Acessórios Automotivos

Site estático pronto para GitHub Pages. Inclui catálogo, busca, filtros, galeria, orçamento com observações e contato pelo WhatsApp.

## Hospedagem

Publique os arquivos desta pasta na raiz do repositório. Em Settings → Pages, escolha **Deploy from a branch**, a branch principal e a pasta **/ (root)**. O arquivo `.nojekyll` mantém a publicação como site estático.

Todos os caminhos de imagens, estilos e scripts são relativos, compatíveis com o endereço de projeto do GitHub Pages.

## Conteúdo

- `index.html`: apresentação, serviços, endereço, horários e contatos.
- `style.css`: layout responsivo e animações.
- `app.js`: catálogo, galeria e seleção para orçamento.
- ``: 24 imagens otimizadas e ícone.

O orçamento abre uma mensagem no WhatsApp; valores e disponibilidade são confirmados pela loja. Nenhuma credencial é necessária para o funcionamento do site.
